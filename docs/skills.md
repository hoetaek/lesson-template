# 슬라이드 제작 스킬

제작·수정·판단·이름·낭독 원고를 위한 다섯 스킬을 포함한다. 이 프로젝트의 코드·데이터 계약과 지원하는 명령에 맞춰 작성했다. 확인일은 2026-11-18이다.

| 스킬                                                            | 맡는 일                                                       |
| --------------------------------------------------------------- | ------------------------------------------------------------- |
| [slide-create](../.agents/skills/slide-create/SKILL.md)         | 목표와 장면 순서를 정하고 새 슬라이드 폴더를 만들어 등록·검증 |
| [slide-edit](../.agents/skills/slide-edit/SKILL.md)             | 기존 ID를 유지하며 글·그림·동작을 수정하고 전후 비교          |
| [slide-principles](../.agents/skills/slide-principles/SKILL.md) | 12개 인지 원리, 사용자 피드백으로 정한 세부 규칙과 근거       |
| [slide-naming](../.agents/skills/slide-naming/SKILL.md)         | 명사형 슬라이드 제목, 대상과 동작이 드러나는 장면 이름        |
| [slide-narration](../.agents/skills/slide-narration/SKILL.md)   | 낭독 원고와 발음·수치 읽기 규칙. 음성 생성·재생은 미지원      |

`slide-principles`는 12개 원리와 사용자 사례를 함께 담는다. 축부터 읽기, 중간 계산, 구체적 예에서 규칙으로 옮기기, 비교 대상 고정, 조작 후 답, 필요성부터 설명하기, 선명한 실습 캡처와 받아 쓸 자료까지 포함한다. 원리 12는 사용자 요청에 근거하며 별도 연구 근거가 미확인임을 그대로 남겼다.

## 현재 구현과의 연결

- 제작 경로는 활동·슬라이드 폴더를 따르고 주소와 브라우저 저장은 ID로 구분한다.
- 슬라이드 제목은 `title`, 장면 이름은 `label`이다. 낭독 원고도 ID로 가리킨다.
- 화면은 `Split`, 장면 진행은 `useProgress()`, 검사는 `npm run capture`를 사용한다.
- 음성 모델·GPU 스크립트·오디오 재생은 없다. 낭독 원고 스킬을 음성 생성 기능으로 설명하지 않는다.

## 한 원본을 두 도구에서 읽기

원본은 `.agents/skills/<이름>/SKILL.md`다. Codex는 이 경로를 읽고, Claude의 `.claude/skills/<이름>`은 같은 폴더를 가리키는 상대 심볼릭 링크다. 다른 컴퓨터로 Git 복사해도 이 저장소 안에서 해결된다. 별도 복사본을 수정하지 않는다. 자동 목록에 아직 나타나지 않으면 루트 `AGENTS.md`의 링크를 직접 읽어 적용한다.

다른 저장소와는 자동 동기화하지 않는다. 새 사용자 규칙을 추가할 때 기존 규칙의 맥락과 현재 구현을 확인하고, 공용 규칙이면 템플릿과 파생 차시에 함께 반영한다. 스킬 규칙을 정비한 것과 기존 차시의 모든 내용이 그 원칙을 충족하는지 재검토한 것은 구분한다.
