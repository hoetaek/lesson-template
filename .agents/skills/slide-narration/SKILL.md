무엇을 말할지는 [slide-principles](../slide-principles/SKILL.md)를 따른다. 루트 `AGENTS.md`와 `docs/authoring.md`를 먼저 읽는다.

## 지원 범위

현재 재생기는 자막만 제공한다. TTS 모델·선생님 목소리·GPU 스크립트·오디오 파일 매핑·음성 동기화는 가져오지 않았다. `npm run narration` 명령도 없다. 실제 음성을 요청받으면 이 한계를 먼저 알리고, 다른 프로젝트의 생성 명령을 임의로 실행하지 않는다. 실제 음성을 만들어야 하는 작업을 원고 작성만으로 완료했다고 말하지 않는다.

## 원고 작성

- 사용자가 점검을 마친 슬라이드의 원고를 `docs/narration.md`에 작성한다. 요청 전에는 빈 원고 파일을 만들지 않는다.
- 각 항목은 `활동 id/슬라이드 id/장면 id`로 가리킨다. 장면 이름·현재 자막·읽는 말·그림이 변하는 순서를 함께 적는다. 이름을 바꿔도 ID는 유지한다.
- 자막보다 친절하게 풀어 쓸 수 있지만, 현재 학생은 원고를 들을 수 없다. 학습에 꼭 필요한 설명을 화면에서 빼고 원고에만 숨기지 않는다.
- 자막을 고치면 해당 원고를 함께 확인한다. 음성 파일을 생성·청취·ASR 확인한 결과가 없는 상태에서 발음이나 동기화 검증을 통과했다고 하지 않는다.
- 원고를 고친 뒤 `npm run format:check`를 실행한다. 화면도 바꿨으면 [slide-edit](../slide-edit/SKILL.md)의 검증을 따른다.

## 읽는 말 규칙 (사용자가 정한 것과 받아쓰기에서 확인한 것)

- 자막은 짧게 두고, 읽는 말은 자막보다 자세하고 친절하게 풀어 말해도 된다(「다음에」 → 「바로 다음 슬라이드에서」, 화면의 표시가 무엇인지 짚기). 영어 이름의 생활 예(AND = 「그리고」)는 읽는 말에 둔다.
- 기호는 뜻으로 읽는다(w → 가중치, b → 편향). 숫자는 한글로 쓴다(「128 점 오」처럼 섞지 않는다). 영문자(엑스·와이·더블유)가 많으면 받아쓰기가 건너뛰므로 줄인다.
- 들어서 다른 뜻이 되지 않게 쓴다. 자연상수 e 는 「이」로 읽으면 숫자 2와 같은 소리라 「자연상수」로 부른다. 받아쓰기가 뜻이 바뀐 말로 들으면(「눕습니다」 → 「높습니다」, 「새 점」 → 「세 점」, 「음수」 → 「응수」) 다른 낱말로 바꾼다(「새로 뽑은 점」, 「마이너스」).
- 좌표 (a, b)는 「a 콤마 b」로 읽는다(「(1, 1)」 → 「일 콤마 일」). 붙여 읽으면 「일 일」이 「11」·「일일」로 들리고, 화면의 쉼표와 같은 모양이라 보는 글과 듣는 말이 맞는다(사용자, 2026-10-06). 화면에 「점 (0, 1)」처럼 「점」이 적혀 있으면 「점 영 콤마 일」로 읽는다.
- 발음이 어색한 낱말은 피한다: 「맞힙니다·맞히는·맞힐」 → 「바르게 나눕니다」·「알아냅니다」·「정답을 낸」. 「네 점마다」는 「네 개의 점마다」로 읽는다. 자막은 그대로 둬도 된다.
- 끝에 「음」이 붙으면(받아쓰기 끝의 「음.」) 마지막 문장을 바꾼다. 「~이에요」로 끝나는 짧은 문장에서 잘 생긴다. 「~입니다」로 끝내거나 문장 순서를 바꾼다.
- 그림이 낭독에 맞춰 움직이는 장면(진리표 줄, 표의 열, 하나씩 찍는 점)은, 낭독에서 그 대상을 말하는 자리를 글자 수 비율로 재서 그림이 나타나는 순서와 원고가 읽히는 순서를 맞춘다. 실제 음성 재생이 연결되기 전에는 동기화를 검증했다고 보고하지 않는다.
