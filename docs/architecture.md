# 구조와 선택

차시 하나를 로그인·백엔드 없이 실행하는 정적 웹앱이다. 수업 내용과 재생기를 분리해 새 수업을 만들 때 공용 화면을 고치지 않게 한다.

| 위치                                             | 책임                                         |
| ------------------------------------------------ | -------------------------------------------- |
| `src/lesson/lesson.ts`                           | 차시 정보, 출처, 활동 순서                   |
| `src/lesson/activities/<활동 id>/index.ts`       | 활동 정보와 슬라이드 순서                    |
| `src/lesson/activities/<활동 id>/<슬라이드 id>/` | 장면·자막·전용 그림·실습·자산                |
| 활동의 `shared/`, `src/lesson/shared/`           | 실제로 여러 슬라이드나 활동이 함께 쓰는 부품 |
| `src/player/`                                    | 탐색·재생·전체/한 장/발표 보기·브라우저 저장 |
| `src/components/`                                | 퀴즈·코드 복사·배치 등 수업에 넣는 공용 부품 |
| `src/domain/`                                    | 타입, 내용 검증, 시간·저장 규칙과 테스트     |
| `src/styles/app.css`                             | Tailwind 테마와 캔버스·일반·발표 상태 변형   |
| `.agents/skills/`                                | 슬라이드 제작·수정·표현·이름·낭독 원고 규칙  |

## 이 경계를 택한 이유

슬라이드의 내용과 그림을 같은 폴더에 두면 하나를 고칠 때 찾아다닐 파일이 줄어든다. 여러 곳에서 실제로 함께 쓰는 부품만 `shared/`로 옮긴다. 장면마다 폴더를 만들거나 실행 중 플러그인을 설치하는 체계는 두지 않는다. 장면에는 React 컴포넌트를 넣어 확장한다.

슬라이드 순서는 활동의 `index.ts`, 활동 순서는 `lesson.ts`에서 명시한다. 자동 파일 검색 순서를 수업 순서로 쓰지 않는다. 폴더를 옮기거나 제목을 바꾸어도 활동·슬라이드·장면 ID는 유지하므로 주소와 이어보기가 끊기지 않는다.

공용 재생기·부품·규칙이 수업 내용을 import하지 않는지 테스트로 검사한다. 실제 차시 데이터는 검사와 빌드에서 ID·출처 연결·자막·장면 길이를 검증한다. 수업 고유 계산이나 실습은 해당 수업의 독립된 테스트와 실제 조작으로 확인한다.

발표는 1280×720 판을 화면에 맞추고, 일반 보기의 본문 폭이 1152px 미만이면 세로로 배치한다. 퀴즈 답과 이어보기 위치는 배포 경로·차시 ID별로 해당 브라우저에 저장한다. 서버 계정이나 원격 제어 없이 학습 자료를 여는 목적에 맞춘 선택이다.

## 자료와 표현 근거

기술 자료는 `src/lesson/sources.ts`와 각 슬라이드의 출처 키로 연결한다. 제작 기준은 [표현 원칙](../.agents/skills/slide-principles/SKILL.md)에 인지 원리·사용자 피드백·논문 및 공식 문서 링크를 함께 적었다. 의존 라이브러리의 출처와 버전은 `package.json`·`package-lock.json`에 있다.

## 확장 범위

현재는 여러 장면을 가진 슬라이드와 객관식 퀴즈를 제공한다. 낭독은 원고 작성 규칙만 있으며 음성 생성·재생, PDF 출력, Python 실행기, 단답형 채점은 아직 없다. 필요할 때 입력·출력·저장·취소 동작을 정하고 추가한다.

이 프로젝트 안의 코드·문서·스킬로 실행과 제작을 마칠 수 있다. 다른 로컬 저장소의 경로·스크립트·환경을 요구하지 않는다. 복사한 다른 차시와의 자동 동기화는 없으므로 공용 수정은 대상 차시에서 검사한 뒤 적용한다.
