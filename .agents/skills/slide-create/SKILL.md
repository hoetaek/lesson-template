description: 이 독립 차시에 슬라이드와 장면을 추가한다.
---

AGENTS.md와 docs/authoring.md를 읽는다. slide-principles의 표현 규칙을 적용한다.
활동 파일에 슬라이드 ID·제목·출처·장면을 함께 정의한다. 큰 그림은 수업 컴포넌트로 나눈다.
기존 운영 앱의 반·계정·공개 범위 모델을 추가하지 않는다.
새 조작·퀴즈 장면에는 waits: true를 주고 다음 장면에서 결과를 설명한다.
수정 후 npm run check, npm run build, 개발 서버에서 npm run capture를 실행한다.
모든 바뀐 장면 이미지는 제작자 외의 검토자가 직접 열어 읽고 통과·수정 필요를 판정한다.
낭독이나 외부 서비스 설정은 별도로 요청받았을 때만 실행한다.
